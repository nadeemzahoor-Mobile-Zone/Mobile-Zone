We offer a variety of mobile phones and accessories, including:

* Mobile Phones
* Phone Covers
* Chargers
* USB Cables
* Screen Protectors
* Wireless Earbuds
* Power Banks
* Smartwatches

## ✨ Website Features

* Responsive design for mobile, tablet, and desktop
* Premium black and white theme
* Product search and category filters
* Shopping cart with quantity controls
* Product price sorting
* Checkout form
* WhatsApp order placement
* Prices displayed in Pakistani Rupees (PKR)

## 📌 Important Notes

* Product names, prices, descriptions, and image URLs can be updated in the `productsData` section of `index.html`.
* Update `SHOP_WHATSAPP` in the JavaScript code before accepting orders.
* This website uses WhatsApp for order submission. It does not process online card payments.
* GitHub Pages hosts the website but does not provide a backend database or order management system by default.
